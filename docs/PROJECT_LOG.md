# UnBoundAI Project Log

This file is the durable source of truth for product decisions made during planning. Update it whenever a decision is approved, revised, or completed. Do not silently replace an approved decision; record the change and its reason.

## Product identity

- Project name: **UnBoundAI** (exact capitalization).
- Product direction: a general-purpose AI assistant and creative development workspace.
- Tagline: **Think freely. Create anything. Build everything.**
- Target device: Android, with Google Pixel 9 Pro XL as the initial design target.
- The product is not an adult gallery.

## Product principles

- Local AI is the default and must remain usable offline.
- Optional online AI providers may be offered only when they have a genuinely free access path; disclose provider limits and do not imply unlimited free usage.
- No required paid API keys, subscriptions, or paid accounts.
- Keep the interface approachable like a chat assistant while providing the capabilities of a professional development workspace.
- Keep the user involved in design decisions. Avoid scope creep and prioritize a working installable Android build.

## Approved design direction

- Combine the ease of ChatGPT with the capabilities of a professional developer workstation.
- Visual direction: dark charcoal base, deep violet and electric cyan accents, clean typography, uncluttered screens.
- Primary experience: central AI conversation area with expandable tools rather than a crowded toolbar.
- Design for mobile first, especially the Pixel 9 Pro XL.

## Planned navigation

1. Home
2. AI Chat
3. App Builder
4. Design Studio
5. Projects

Code Studio may open as a workspace within App Builder or as a separate workspace. This has not yet been finalized.

## Initial home-screen direction

- UnBoundAI branding.
- A prominent prompt: “What do you want to create?”
- Quick access to core tools.
- Recent projects.
- This is the first interface planned for design and implementation; exact layout remains to be approved.

## Planned product areas

- AI Chat: local models first, optional free online providers, conversation history.
- App Builder: create Android applications from natural-language descriptions.
- Design Studio: create and refine interface designs.
- Code Studio: write, edit, and debug code.
- Projects: save and manage work in one place.
- Settings: model management, privacy, appearance, and data management.
